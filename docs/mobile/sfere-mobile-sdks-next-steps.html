4. Steps, in order

Each phase is one working session. Before any heavy step (simulator, emulator, Gradle, Xcode), check memory as the global rules say: one heavy job at a time, and stop the daemons afterwards.

5. Rules for every round

  • Same on both platforms. Any change to what one SDK sends is made on both in the same commit, and the task Parity: compare iOS and Android payloads must report every event as "same".
  • Tests before done. Run Test: both SDKs (Cmd+Shift+B) and quote the real counts.
  • No vendor names. Never name the ingestion vendor; say "ingestion endpoint".
  • Secrets go only in the project .env (git-ignored, chmod 600), with project-specific names such as SFERE_MOBILE_STAGING_WRITE_KEY. Tests never read the real .env.
  • Git: commit only when the user asks, and never with an AI attribution trailer.
  • Machine safety: measure memory before simulators, emulators and builds; never run two of them at once; stop the Gradle and Kotlin daemons and shut down simulators when done.
